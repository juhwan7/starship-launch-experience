# AGENTS

Read `PROJECT_STATUS.md`, then `docs/RESEARCH.md`, `docs/DECISIONS.md`, `docs/ASSETS.md`, and `docs/QA.md` before changing the project.

Rules:
1. Do not replace confirmed current V3 facts with older Starship versions.
2. Never present cinematic interpolation or cutaway geometry as exact telemetry/manufacturing data.
3. Preserve CC BY 4.0 model attribution.
4. Keep `fallback.html` functional when changing the high-detail path.
5. A visual feature is not complete until it is tested in the deployed GitHub Pages build.
6. Never commit secrets.
7. Prioritize visual realism, camera continuity and mobile stability over adding unrelated UI.
8. Record failed visual/performance experiments in `docs/FAILED_EXPERIMENTS.md`.
