# Concept

The page is a browser-native cinematic documentary rather than a traditional site. The visual grammar is continuous movement: **environment → full vehicle → ground systems → internal explanation → propulsion → ignition → atmosphere → space → separation**.

Primary design goals:
1. Scale is legible before detail.
2. Camera transitions hide scene-scale changes.
3. UI remains peripheral and minimal.
4. Confirmed engineering facts and cinematic reconstruction remain distinguishable.
5. A user can watch the full sequence or interrupt and explore.
