# Asset provenance and licenses

## High-detail Starship Block 3 GLB

Runtime URL:
`https://cdn.jsdelivr.net/gh/haskaomni/blueprint@main/public/models/starship-block3.glb`

Distribution repository:
`https://github.com/haskaomni/blueprint`

That repository documents the model as based on:
- Title: **SpaceX Starship Block 3**
- Author: **Clarence365**
- Original: https://sketchfab.com/3d-models/spacex-starship-block-3-6f6c6f88a3eb4b4d822fdca66733fbb2
- Author profile: https://sketchfab.com/clarence365
- License: **CC BY 4.0** — https://creativecommons.org/licenses/by/4.0/

The optimized model distributed by `haskaomni/blueprint` is approximately 8 MB and retains a multi-node hierarchy. The high-detail page loads it at runtime rather than redistributing a second copy in this project.
